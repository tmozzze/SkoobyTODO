# SkoobyTODO 

Простой REST API сервис для управления задачами, написанный на Go. Приложение реализует чистую архитектуру и работает с данными в памяти (In-Memory).

## Структура проекта

```
.
├── cmd/
│   └── app/
│       └── main.go        # Точка входа в приложение
├── internal/
│   ├── handlers/          # HTTP обработчики
│   ├── config/            # Конфигурация приложения
│   ├── storage/           # Слой данных: потокобезопасный In-Memory.
│   ├── models/            # Модели данных (Task)
│   ├── service/           # Бизнес-логика
│   └── utils/             # Вспомогательные функции (парсер .env)
├── Makefile               # Команды для управления проектом
├── Dockerfile
├── go.mod                 # Модуль
├── .env.example           # Пример .env
└── .gitignore
```
## Требования для запуска
* `Docker`
## Запуск приложения

### Предварительные требования
* На вашей системе должнен быть установлен `Docker`
* Убедитесь, что файл `.env` существует и сделан по образцу `.env.example`
Для удобства запуска и тестирования в проекте используется Makefile.

### Шаги запуска

1. Запустите приложение в терминали bash
```
make run
```
2. Дождитесь запуска сервиса
3. Ваше сервис готов к использованию


## Команды `Make` для тестирования API
### 1. Создать задачу
```
make test-create TITLE={Ваша задача} DESCRIPTION={Ваше описание}
```
Пишите команду без "{ }" там должен быть просто текст

### 2. Получить список задач
```
make test-getall
```
Выведет на экран список всех задач

### 3. Получить задачу по ID
```
make test-getbyid ID={id задачи}
```
Выведет на задачу по айди

### 4. Обновить задачу по ID
```
make test-update ID=2 TITLE=title DESCRIPTION=description COMPLETED=true/false
```
Обновляет данные в задаче по айди, на те, что указаны

### 5. Удалить задачу
```
make test-delete ID={id задачи}
```
Удаляет задачу
